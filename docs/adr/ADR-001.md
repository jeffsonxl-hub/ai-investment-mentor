# ADR-001: Research Agent — Monolithic for V1

**Status:** Accepted

**Date:** 2026-07-03

## Context

The research capability could be split into multiple specialized agents (market data, news analysis, fundamental research, etc.).

## Decision

In V1, a single `research-agent` handles all research responsibilities. No sub-agent decomposition.

## Rationale

- V1 scope is narrow — over-splitting adds coordination complexity without clear benefit.
- Single agent simplifies the decision flow and memory architecture.
- Decomposition can be revisited in a later ADR once concrete pain points emerge.

## Consequences

- `research-agent` becomes the most complex single agent in the system.
- Future split will require extracting responsibilities from a tightly coupled module.
